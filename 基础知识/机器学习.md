# 总括：机器学习的知识体系
机器学习（Machine Learning,ML）是人工智能的一个重要分支
+ **核心思想**：不直接为计算机编写解决所有问题的规则，让计算机从数据中**学习规律**，完成**预测**、**分类**、**生成**或**决策**

### 1）按训练信号的来源分类

#### （2）无监督学习

### 2）按照已有知识的利用方式分类

#### （4）持续学习
## 一、监督学习
### 1.什么是监督学习(Supervised Learning)
给模型提供输入**数据**以及**对应的正确答案**，让模型学习输入与答案之间的关系
+ 预测结果和真实标签不一致：产生损失
+ 模型通过反向传播和梯度下降调整参数，使预测结果逐渐接近真实标签
### 2.监督学习的两大任务
#### 1）分类 Classification
预测样本属于哪个类别
#### 2） 回归 Regression
预测一个连续数值
### 3.监督学习的优缺点
#### 1）优点
+ 训练目标明确
+ 容易衡量模型效果
+ 在分类、预测等任务中应用广泛
#### 2）缺点
+ 需要大量标注数据
+ 数据标注成本可能很高
+ 模型容易受到标签质量的影响
## 二、无监督学习(Unsupervised Learning)
### 1. 什么是无监督学习
训练数据没有人工提供的标准答案，模型需要**自己寻找数据中的结构和规律**  
例如：模型根据图片之间的相似性，把它们分成不同的群组  
注意：模型不一定知道这些群组分别叫什么，它只是发现了数据之间的相似性
### 2.无监督学习的典型任务
#### 1）聚类 Clustering
将相似数据自动归为一类  
常见算法：
+ K-Means
+ DBSCAN
+ 层次聚类
#### 2）降维 Dimensionality Reduction
将高维数据转换为低维数据，同时尽可能保留重要信息  
常见算法：
+ PCA（主成分分析）
+ t-SNE
+ UMAP
#### 3）异常检测 Anomaly Detection
发现于大多数数据明显不同的样本
### 3.无监督学习与VAE
VAE（变分自编码器）是一种生成模型，也是一种概率潜变量模型
它通过编码器将数据映射到潜在分布，再通过解码器重构数据  
VAE通常不需要人工为每张图片提供类别标签，因此常用于无监督表示学习和生成建模  
严格来说，VAE使用了重构目标和KL散度构造的训练信号，所以它也可以从自监督学习的视角理解
## 三、半监督学习（Semi-supervised Learning）
少量标签 + 大量无标签  
基本思路：
1. 使用少量有标签数据学习初步分类能力
2. 利用大量无标签数据寻找数据分布规律
3. 结合两种信息优化模型
常见方法：
+ Pseudo-labeling（伪标签）
+ Consistency Regularization（一致性正则化）
+ Mean Teacher
举个例子：
模型看到一张没有标签的图片，认为它有95%的概率是猫。  
那么就可以把猫作为这张图片的伪标签，再将这张图片加入后续训练。  
当然，伪标签可能出错，因此需要一定的**置信度筛选**和**训练策略**。  
**适用场景：** 医学影像、工业检测、自动驾驶等标注成本较高的领域。
## 四、自监督学习（Self-supervised Learning）
现代大模型的重要基础（扩散模型、视觉模型、大模型）
### 1.什么是自监督学习
不依赖人工标注，从数据本身构造学习任务，让模型通过完成这些任务来学习数据的特征  
例如：遮住一章图片的一部分，让模型预测被遮住的部分  
原始数据就是训练数据，被遮挡的部分构成了监督信号

|数据类型|自监督任务|
|:---:|:---:|
|文本|根据前面的文字预测下一个词|
|图片|根据可见区域恢复被遮挡部分|
|视频|根据前面的帧预测后续帧|
|语音|预测被遮挡的语音内容|
### 2.为什么自监督学习重要
现实世界数据非常丰富，人工标注数据非常昂贵
例如：  
假设我们有10亿条文本数据。  
如果采用传统监督学习，需要人工为这些文本构建标签。  
但是如果让模型预测下一个词，就可以直接利用原始文本构造训练任务  
这就让模型能够从海量数据中学习。
### 3.代表性方法
+ BERT：通过掩码语言模型学习文本表示
+ GPT系列：通过自回归预测下一个Token学习
+ MAE：通过遮挡和重构图片学习视觉表示
+ SimCLR：通过对比学习构造自监督任务
**自监督学习可以采用对比学习、重构学习、预测学习等方式**、
## 五、强化学习
通过试错学习决策  
让模型在一个环境中不断尝试，根据行为产生的奖励或惩罚来学习
主要包含四个部分：
+ Agent：智能体，也就是学习的模型
+ Environment：环境。智能体所处的世界
+ Action：动作，智能体可以采取的行为
+ Reward：奖励，环境对行为的反馈  
强化学习的目标通常是最大化长期累积奖励
### 1.强化学习的典型应用
+ 游戏AI：AlphaGo
+ 机器人控制：学习行走、抓取物体
+ 自动驾驶：决策和控制研究
+ 大语言模型：RLHF(Reinforcement Learning from Human Feedback，人类反馈强化学习)等训练方法
>> RLHF让模型利用人类对回答质量的偏好进行进一步优化
>> 例如：
>> + 人类更喜欢回答A而不是回答B
>> + 模型学习这种偏好
>> + 最终使输出更加符合人类期望
>> 现代大模型的后训练也不只有RLHF，还存在DPO等不直接采用传统强化学习流程的方法
